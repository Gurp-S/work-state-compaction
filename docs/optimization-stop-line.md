# 优化停止线

压缩层已到当前测量分辨率以下的收益区。继续加机制只会积累复杂度，不会带来可复现的质量提升。
本文件是判断标准；[stopline.py](../benchmarks/coding_compaction_v1/stopline.py) 是它的可执行版本，CI 中为独立 job。

## 三条准入标准

一项机制改动必须**同时**满足，否则不做：

1. **机械可判定**：引擎能不看模型、不看语义价值地判断结果对错（哈希、事件顺序、原文比对、字节预算）。
2. **消除系统性错误**：错误在重复运行中稳定出现，不是采样噪声、单例提示词差异或精确串匹配的度量伪差。
3. **不扩张**:不增加模型调用次数，不新增需要长期维护的机制、配置或发布字段。

## 已裁决的清单

| 事项 | 裁决 | 理由 |
| --- | --- | --- |
| 标识符逐字校验与机械回填 | **做**（已实现） | 机械可判定；源事件里有的原词直接抄回，无模型调用 |
| 扩大评测（更多用例、更多轮、重复采样） | **做**，属于测量 | 零机制复杂度，降低结论方差 |
| 选择事实 / 验证适配器 / 查询策略 / 写回 / 前沿生成器 | 不做 | 已证零收益或负收益，且都要求模型多做判断 |
| 第二遍模型自检 / 重写 / 状态再压缩 | 不做 | 多一次调用只是把同一损耗挪到下一轮 |
| 提高证据索引行数或把原文给模型 | 不做 | 只涨字节；Discover/Retrieve 已 1.00 |
| 追平 native 的字节比例（matched gate） | 不做 | 搜索只能压不能涨；为对齐而填充是反目标 |
| probe 单例 0.75 调到 1.00 | 不做 | 度量伪差，调它等于对用例过拟合 |
| 冷存回收策略 | 暂不做 | 已有 256 上限；容量是宿主决策 |

## 标识符逐字校验的边界

实现见 `anchor_facts` / `repair_identifiers`（`benchmarks/coding_compaction_v1/live.py`）：

- 只在条目写入位置 ±64 个事件内做锚定，扫描量与单轮增量成正比，与整个会话长度无关。
- 只检查 `decision` / `verification`；只回填源事件中**原样存在**的标识符，最多 4 个，追加 ≤120 字节。
- JSON 键名（`file_path`、`new_string` 等）和编码载荷里的 JSON 标点残片（引号、花括号）不算标识符，不参与回填。
- 回填是幂等的；第二轮再校验应为空。
- 已失效条目的版本短语（如 `V4 checked`）同时从模型状态与索引中过滤，避免旧验证经 `done`/`unknown` 回流。
- **零模型调用**：审计和回填都不经过模型；禁止把缺口交给模型自修。

## 执行映射

| 标准 | 可执行检查 |
| --- | --- |
| 不新增机制 | `check_module_surface`：`src/wsc` 顶层模块必须等于冻结清单；新增需显式改清单 |
| 已移除 API 不回流 | `check_removed_apis`：`include_selection_facts`、`prefix_index` 查询策略、`publication_policy`、`write_back` 等不得出现在 `src/wsc` |
| 不增加模型调用 | `check_call_budget`：thin / WSC / WSC-lean 两轮各 ≤2 次调用（含回填，即每次压缩 ≤1 次） |
| 引擎扫描有界 | `check_audit_bound`：2000 事件 × 60 条目 < 1.5s，且锚定不得越过窗口 |
| 呈现契约不退化 | `acceptance.py`：无 JSON 槽位、无源路径、预算裁剪、去重、失效、状态缺口 |
| 质量不倒退 | `live.py` / `longhorizon.py`：比例、probe、recall、证据 hash、漂移 |

旧 `live` / `longhorizon` 指标已饱和，仅作诊断；三臂判决以 [eval-redesign-v1.md](eval-redesign-v1.md) 的行为续作方案为准。

## 变更流程

1. 新机制默认拒绝；要进入主路径，先在本文档裁决表中给出准入三条的证据。
2. 顶层新模块必须在 `ALLOWED_MODULES` 中显式登记，CI 失败即提醒复审。
3. 停止线检查失败不允许用跳过或放宽预算解决；只能撤销改动或修改裁决并留下理由。
