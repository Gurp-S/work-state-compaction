# 严格 JSONL 两次边界对比预登记

新任务；不重跑 bounded-command、opaque 或旧选材样本。现有读取器实际接受重复 type 键并覆盖前值，也接受 NaN 并标记 parse_complete，有限复现已保存于 `validation/strict-jsonl-study-20261023/baseline-reader.json`。这不是此前已修的 UTF-8 替代解码问题。

任务在隔离冻结副本新增 `wsc.strict_jsonl.parse_strict_rollout`，真实旧读取器原字节复制为 `src/wsc/native_rollout_snapshot.py`。所有原 src 与实际 AGENTS 都受保护；默认读取器不改。父代理只准备任务、私有验收和运行流程，不实现任务答案。

阶段：共享源任务拒绝任意对象层级重复键（5项）；第一次边界后拒绝非有限常量及浮点溢出（8项累计）；第二次边界后新增单行原字节限额（11项累计）；最终交接核对当前版本、5/8/11证据范围与未覆盖问题。真实部分尾行、不递归解码字符串、原始字节身份和物理LF行号始终保留。来源已在内存，单行解析预算不是整个来源读取内存上限。

每个编码阶段最多24响应、600秒、1,500,000总tokens；各臂交接4响应、120秒、400,000tokens。每次原生压缩1响应、180秒、250,000tokens。沿用既有明确预算，保留所有超额与未知回执；失败、封顶、缺final、未知用量、保护文件变化或验收失败即停止后续，不重启、不扩大预算。

在首次推理前，正常插件/技能发现及固定一次零推理预热后，在同一原生进程、同一绝对cwd创建并留存B、C1、C2，注入同一实际源阶段执行事实，使用既有NativeGroupAdmission核验真实宿主一致。原生二进制、配置、模型、工具、权限不改。

固定顺序：B线程执行共享源任务；冻结源阶段终态。C1经首个host_messages边界执行非有限数值阶段；C2经带来源/祖先冷档校验的第二边界执行预算阶段；C2交接。父代理审阅实际最终文本和绑定回执（最多等待600秒、0新增推理）；C资格成立后归档C并原位恢复共享源代码，原B线程原生压缩后执行相同非有限阶段，再原生压缩后执行相同预算阶段及交接。保持同cwd，禁止父代理代修任务产物。B压缩前及后重复注入同一当前阶段执行事实，供实际执行绑定；不修改原生压缩提示。

原生B压缩费用计入B，WSC生成调用0；共享源成本另列。每回合按新增response_id计量，全部线程归档与阶段回执核对。报告质量、完成/中止、输入/缓存/输出/推理、耗时分别列示，金额未知保持未知。只有两臂同范围完成并通过交接审阅，才计算同成功范围的相对成本。

这是固定顺序的单任务、两次边界实验，不是长期稳定性或全目标证明。它增加了先前单边界任务没有的数值约束、预算变化和跨阶段证据适用性；不根据结果修改验收或删除失败成本。
