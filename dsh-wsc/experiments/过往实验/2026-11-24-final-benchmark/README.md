## 裁定

1. v3r：成本最低、压缩最少、重读最少、终态 8/8 全过、引文全部可回查。
2. v2f：同族次选，成本 +19%，没有持久 seq。
3. w80：墙钟最快，但检查点最大、索引把 spill 路径带进检查点，且有一例违反
   “不要改源码”的回合约束（4/5）。
4. native：成本最高、压缩最多、逐字需求几乎不保留；一例 52/54。
