# 2026-11-24 v3 矩阵：索引 / 增量抽取 / 持久序号 / 需求覆盖块

在 v2f 上分别只动一个旋钮，long-40 各 2 次、constraint-25 各 1 次：

- `v3i`：`evidenceIndexRows: 0`（去掉证据索引）。
- `v3x`：`extractDelta: true`（抽取只报新增/变化关系）。
- `v3r`：`receiptSeq: true`（回执引用会话 seq，可回查）。
- `v3b`：三个全开。
- `v4q`：`v3r` + `requirementBoard: true`（机械需求覆盖块）。

裁定：v3r 成为最终默认，原因是成本中位与 v2f/v3b 持平而压缩次数最少、
引文 100% 可解析、需求覆盖 32–35/35。索引（v3i）去掉后成本没有下降；
增量抽取（v3x）反而更贵；需求覆盖块（v4q）没有质量收益，成本更高，保持关闭。
