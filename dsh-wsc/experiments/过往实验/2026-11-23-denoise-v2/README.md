# 2026-11-23 v2：ledger 去噪 + R1–R3 修复

v2 的配置等于 `dclean`：`ledgerCapBytes 8000` + `ledgerDenoise` + 渲染期去噪。
`v2f` 使用同一配置，但引擎已经合入 R1–R3：压缩后重置 read-dedupe（R1）、
错误钉扎只认真正的失败（R2）、证据索引剔除环境路径（R3）。

裁定：v2 成为 v3 的基线。R1–R3 的收益主要在尾部读取和检查点噪声，成本差异落在
压缩次数的会话方差内；v2f 的 long-40 成本中位 0.858，检查点中位 12.9k。
