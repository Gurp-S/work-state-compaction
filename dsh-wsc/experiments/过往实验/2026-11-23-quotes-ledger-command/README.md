# 2026-11-23 长跑臂：quotes / ledger / command-state / 工作集 / 卡片 / 去噪

场景：long-40（40 轮真实改造）与 constraint-25（首轮写入 BLUEBIRD，末轮禁止读文件）。

- `w80`：quotes 全量账本，不做 cap/去噪，作为稳定参照。
- `ledger`：`ledgerCapBytes: 8000`，按 requirement/constraint 优先级保留。
- `cmd`：`controlMode: command-state`，把后来的用户请求压成状态行。
- `cmdws`：cmd + workingset。
- `ws` / `ws2`：workingset v1 / v2。
- `cards` / `lcards`：矛盾卡片；`lcards` 同时开 ledger。
- `dclean`：`ledgerDenoise: true`（与后来的 v2 同配置）。

裁定：ledger 是唯一超过 w80 的变体（成本约 −10%，检查点约 −8%），晋升候选；
cmd 在 40 轮高压缩区出现“压缩抖动→重读”螺旋；工作集与卡片没有降低读取或成本，
不再进入后续主线。`dclean` 的去噪结果直接成为 v2 的基线。
