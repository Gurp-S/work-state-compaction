# WSC v1 冻结与巩固清单（2026-11-20）

- 冻结版本：`wsc_nosig` —— 阈值触发压缩 + EXT 抽取契约 + 引擎值账本 + 条件化恢复契约。
- 对照对象：`dsh_native`。
- 结论来源：[今日目标达成表（11-19）](goals-20261119.md)、[重复采样记录（11-19）](wsc-repeat-sampling-20261119.md)、[设计归档](wsc-design-meta-20261119.md)；A/B/C 三组实验数据见本文第六节。

## 一、为什么在此收口

A/B/C 三组最小实验（各 5 次独立采样，压缩与恢复推理分开统计）给出同一结论：

- **配置不是原因**：把原生压缩的输出上限对齐到与 WSC 相同后，原生压缩推理仍在 0.4k（DeepSeek）/ 2.2k（GLM），WSC 仍在 4.9k / 17.2k。
- **修订判定不是主因**：取消修订判断后，DeepSeek 压缩推理不降，GLM 只降约 22%，且恢复推理上升，总成本基本不变。
- **next 呈现没有稳定收益**：DeepSeek 两组 5 次采样符号相反，合并 10 次后均值略降但区间大幅重叠；GLM 略升。

因此，剩余推理是“受约束的语义抽取与过滤”的固有成本，属于 WSC 的设计特性。继续微调只能得到噪声级收益，进入停止线禁止的噪声区。**优化阶段结束，转入功能巩固。**

## 七、变更纪律（巩固期的硬规则）

1. **默认路径只接受行为中性整理**：注释、命名、文档、测试可以改；契约、阈值、状态规则、值账本不改。
2. **任何默认改动必须重跑第五节的四项检查**，然后两模型 × 5 次独立采样，质量与成本同时报告。
3. **成本差异落入区间重叠时，视为无收益**，不得据此改默认。
4. **取消修订、精简契约、引擎全权持值**等大方向实验只能作为独立臂或独立分支，不得直接修改默认。
5. **失败必须归因** model / recovery / wsc；模型没照做不加机制。
6. **大改另立项目**：如要突破当前推理成本，属于机制重做，需单独的提案与验收口径，不与巩固混在一起。

## 八、已知边界

- GLM 长用例成本约为 native 1.9×；DeepSeek 长用例仅分布层面接近。
- 全部用例为合成会话，真实 20+ 轮仓库会话与人工 oracle 尚未采集。
- 多键取回与回合上限已补离线断言（批量取回、取回+读取同轮、三回合上限、未知键回传），尚无真实模型的多键压测。
- 多轮压缩循环已有离线断言（24 轮、12 次阈值压缩）与真实模型复跑（24 轮、6–7 次压缩、两模型各 5 次，记录的 next 均只出现一次）；仍未覆盖 60/80 压力触发与 1M 窗口。
- 格式重试在部分 GLM 批次出现（约 3–6% 调用），本轮 A/B/C 为零重试。
- 生产路径（dsh-wsc）尚未接入选定机制；接线不属于巩固范围，需另行决定。
