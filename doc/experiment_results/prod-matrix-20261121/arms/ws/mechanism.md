# 仅工作集臂（pmx-ws-20261121）

1. **与 WSC 基线的唯一差异**：`passageWorkingset=true`（v2：最多 6 个文件、单项 700 字节、单节 2500 字节）。
2. **作用**：检查点增加 `## Working set` 段，摘录当前相关文件的小节，试图让恢复后的模型少重新读文件。
3. **假设**：原生臂检查点携带部分源码，而 WSC 检查点不带文件正文，导致 WSC 在恢复后多花 read/shell 回合；工作集用固定的小额字节预算买回这些回合。
4. **风险**：工作集会增大每个检查点，若模型仍重读文件则纯增成本；由矩阵按场景定价。
