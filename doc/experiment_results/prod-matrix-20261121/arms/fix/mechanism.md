# WSC nosig + 两项候选修复（pmx-fix-20261121）

1. **在 WSC 基线之上启用两项候选**：
   - `controlMaxBytes=6000`：控制原文按最新优先逐字保留，超出预算时整条省略最旧消息，并写出 `control omitted` 披露；
   - `passageWorkingset=true`：把工作集（相关文件的小节摘录，v2：最多 6 个文件、单项 700 字节、单节 2500 字节）放进检查点，试图减少恢复后重新读文件的回合。
2. **其余机制与 WSC 基线相同**：nosig 单次抽取、账本、状态投影、值账本、证据索引、跨压缩 journal。
3. **定价目的**：本臂是“合并包”，只回答“打包是否更好”；拆分归因由 `cap`（仅上限）与 `ws`（仅工作集）两臂给出。
4. **可观察差异**：长程场景中控制段稳定在 6048 字节并出现省略披露；检查点中多出 `## Working set` 段，检查点总体积比基线更大（工作集抵消了控制截断的节省）。
