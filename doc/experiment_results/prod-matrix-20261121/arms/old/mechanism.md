# 同日旧形状基线（pmx-old-20261121）

1. **用途**：在优化代码上用配置复现旧检查点形状，解决“历史基线是不同时段跑出来的”这一混淆。
2. **开关**：`stateFromControls=false`（需求只看当前区间）、`passageRecent=false`、`passageLatest=false`、`warnRatio=0.6`；其余与 WSC 基线相同。
3. **结果**：长程成本 ¥0.405–0.513（中位 ¥0.459）、压缩 21–34、步骤 235–293；55 个检查点中 48 个（87%）状态块为空，0 个最近变更块。
4. **意义**：与同日 `w80`（¥0.429、7/73 空状态）对比，说明优化包不是“用成本换质量”，而是同时更省、状态更可用。
