# 槽位归并臂（cmb1-opt-20261118）记忆机制

1. **写入**：身份键仍是“实体 + 槽位字符串 + 上下文”；抽取按人物串行（EXTRACT_SEQ），每轮把“已有实体 / 已有属性”交给模型，让命名在同一人物内收敛。
2. **槽位归并**：构建时对同实体槽位做字符串相似度匹配，普通情况阈值 0.6，检测到用户改口时降为 0.2，把同义写法并到既有槽位；泛称累积型槽位（建议/提醒/约定/事项）先拆成带值特征的唯一槽位，避免第 N 条建议覆盖第 N-1 条。
3. **检索**：在基线检索上启用 RETRIEVE_V2（问题+线索词参与实体内排序）和 COVER（按线索词为结果预留席位），再做 RRF 融合；结果仍只给结构化行，不附带来源原文。
4. **冲突消解**：归并后的同一槽位由新值覆盖旧值；改口通过低阈值归并到原槽位；pending 池仍保留（本臂 143 条），以 PENDING_BINDING 返回。
5. **遗忘**：无删除；只有 lifecycle=closed；历史修订保留用于 as-of 读取。
