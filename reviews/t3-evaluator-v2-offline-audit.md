## 结构性原因与修复边界

旧 T3 评分器把参考实现的临时表名 projects_migrating 和 sqlite3.DatabaseError 当作公开要求。实际契约要求保留既有数据、原子拒绝和调用方事务，不限定这两个实现细节。新增独立 acceptor_t3_v2.py，以 SQLite 创建事件观察暂存表，对既有暂存表及无关表验证结构和行保留；覆盖 sentinel 与目标表结构两种冲突布局。安全拒绝接受不同异常类型，但拒绝前改变状态仍失败。支持不同名称、带引号名称和无暂存表的原地迁移；无法覆盖的附加数据库暂存行为标为不可判定，不计正确或错误。

旧最终消息收集把提问工具在界面上的展示也当成模型最终答案，导致“最终答案不唯一”。新增 final_origin.py，绑定原始 rollout SHA、模型消息类型、当前 turn 自身元数据及原文；仅在工具调用 ID 和原始调用类型完全对应时排除展示消息。未知来源、改写文字、身份冲突或缺少自身回合绑定均不可判定，不靠 ID 前缀或关键词猜测。

结构化答案附带的 status 等字段独立记录为未评语义；不据此推断真假。显式 null 为未知，不算错误事实，同时报告回答覆盖率和以全部必答字段为分母的精确召回，避免只答少数题抬高分数。自由文本不做语义裁判。
