# Cursor 上下文机制对照：可借鉴部分与当前 WSC 差距

2026-10-23。依据 Cursor 官方公开文章与当前本地源码；不是 Cursor 私有实现审计。本机 `D:/lea/cursor` 是空目录，常见用户安装目录未找到 Cursor 安装项；没有据此声称遍历了整台机器或取得其内部代码。

## 官方公开证据

- [Dynamic context discovery，2026-01-06](https://cursor.com/blog/dynamic-context-discovery)：长工具结果保存为文件；压缩后保留历史文件入口，缺失细节可搜索恢复；工具描述按需加载。其价值假设是减少预先注入，而非让摘要承担全部信息。
- [Training Composer for longer horizons，2026-03-17](https://cursor.com/blog/self-summarization)：Composer 将多次自摘要及之后的执行共同纳入强化学习训练，最终任务奖励也作用于摘要。文中报告的摘要效率来自特定模型训练与实验；复制短摘要提示不能取得同等能力。
- [Improved token efficiency for longer agent runs，2026-09-23](https://cursor.com/blog/improved-token-efficiency)：减少常驻描述，按需加载低频工具，保持缓存前缀稳定并分离可变环境信息；同时观察质量、成本、延迟和工具错误。缓存接口的具体可用性需要另行核验，不能从这篇文章推定当前原生入口可配置。

这三部分分别属于可移植的上下文组织、模型训练、宿主请求组装。Cursor 的自身效果数字不充当 WSC 收益证据。本文不移植其子代理方案，遵循本项目当前代理直接完成的约束。

## 当前代码已经有什么

`src/wsc/generation_frontier.py::offer` 已导出全部原始来源、逐来源摘录文件和目录，未选入热材料的旧来源仍可读取。`span_selection.py::compile_spans` 在模型返回后按完整来源重新解析引用，原文不是由模型重写。这与文件化历史、按需回查已有重叠，不另起同功能存储或检索系统。

仍有一个具体差距：构造器把上一轮精确摘录的父来源加入 kept；offer 随后把这些来源的全部 spans 再次放入生成输入。此前只需要一小段观察，下一轮却可能重读整条长输出。这是源码确认的展开行为；其对实际总成本及质量的影响尚未成立。

另外，`experiments/run_quote_selection_probe.py::output_schema` 把全部 span 引用枚举放入输出 schema。仅缩短材料正文，并没有消除这部分重复提交。取消枚举也可能增加非法引用和失败成本，因此不直接删除。

## 候选与实施顺序

2026-10-23 后续真实样本复核：上一视图 16 条摘录涉及的 5 个父来源，全部已被模型明确选为完整来源；严格保留该选择时，本样本没有可消除的额外父来源展开。此前源码观察不等于这个真实样本的收益依据。因此没有立即实施摘录粒度候选，也没有为其新增付费实验。证据见 `validation/span-schema-20261023/granularity-audit.json` 和 `2026-10-23-span-schema.md`。以下保留原候选描述，不能读作已证明收益。

优先候选：复用上一轮已选的精确摘录，保留当前模型理解和全部新增事件，旧来源其余部分通过既有文件入口读取。完整来源、控制记录、原观察时间与身份绑定继续保留；摘要或旧选择不自动成为当前事实。这个候选针对重复展开的实际入口，不新增语义真值字段，也不依赖引擎替模型判断任务重点。

实施前的三个问题：

1. 结构性原因：当前增量生成只在来源粒度筛选，摘录粒度的历史选择在下轮被扩大为整条来源。
2. 对应规则：保持已选摘录粒度；明确选入的完整来源仍完整，新增事件与必要控制不因旧选择被删掉，其他内容可按原身份回查。
3. 正确性检查：旧摘录逐字一致；跨来源/边界变更不能偷换引用；遗漏部分确实可读取且可重新选中；授权变化仍在执行层拒绝。最终实验还需观察压缩后任务判断与完整费用，而非只比较输入长度。

这是待验证假设，不是已实现方案。先处理已有产物中错误解释与完整证据并存时的下游资格：41 字符冒称 SHA-256 的问题仍未解决；已修目录身份也未取得新的模型行为证据。当前不启动 B/C，不重复已有生成实验挑选结果。随后若实施候选，保留小版本，用同一来源、相同实际 bootstrap 的独立准入进行一次预登记实验，将生成、回查、失败和后续执行一并计入。

训练自摘要是值得长期参考的评价思路，但当前没有 Composer 的训练能力或可迁移权重，不能包装成 WSC 即将获得的实现收益。原生 Codex 对照保持不变。
