# 自动选择入口候选与一次失败生成的复核

## 目标与结构性问题

用户恢复持续 Goal 后移除了关机及额度停止条件。本轮接续桌面 WSC 目标，不重复单题 B/C，不把当前规则检查当作整体超越原生。原生普通执行未改，没有使用子代理，也没有改动根目录 python/ 下的并行工作。

上一轮的有效对照依赖父代理手工填写选择结果：source ID、底层 payload 路径、字符范围和 SHA-256。实际 `WSC.material()` 只给模型公开事件文本，不提供这些底层路径。这里把语义选择与机械定位混在同一模型输出契约里，已有结果不能证明自动入口可用。

本候选将两项职责分开：调用方模型选择来源、原文与可修订理解；程序只编译精确引用。`quote_selection.py` 是显式前端，不内置语义策略、不排名、不扫描实时文件、不自动重试。来源短标识只是同一快照内的序号映射，不产生新来源或新观察。

## 实现边界

- `SelectionDraft` 携带模型结果与实际 Usage。`QuoteSelectionGenerator` 经现有 `WSC.generate → prepare → stage` 入口工作，不绕过来源授权、版本、预算或发布契约。
- 模型可返回来源选择、已有理解引用、新理解、发现线索及原文 quotes。四类原有选择关系继续交给既有解析和 CAS 校验。
- 引用原文必须在指定公开文本中唯一精确出现；换行、Unicode、空格不自动归一化。重叠重复也算歧义。未提供的来源、实时路径和新增自称已验证字段不被该前端接受。
- `Excerpt.basis=public_text` 明确区分生产者登记的公开文本与旧的 payload 路径。公开文本和 payload 都属于不可覆写来源记录；公开文本不是隐式实时文件读取。默认 payload 路径仍保留。
- 语义正确性仍未认证。模型可以显式复用或修订理解；历史支持不自动变成当前适用。

## 真实生成：失败保留，没有重跑

目录：`D:/agent-task-runs/wsc-quote-selection-20261023-v1`。

来源为既有20条修复前原始事件，含原始公开诊断；没有输入人工选择文件、要求保留的观察清单、完成后的答案或修复后源码。这里只研究生成入口，不执行修复、不取得 C 续接资格，也不作 B/C 对照。

模型 `gpt-6-luna / max`，原生 app-server；空的只读生成工作区，单回合最多2响应、180秒，无重试。结构化输出接口由当前本机二进制导出的 schema 和 [官方 App Server 文档](https://learn.chatgpt.com/docs/app-server) 核对；schema 只限制输出结构，不证明内容正确。普通任务原生对照没有改配置。

实际1响应、46.859秒模型阶段；69,712非缓存输入、0缓存输入、5,257输出，其中4,396为原生报告的 reasoning output；合计74,969 tokens。无任务工具调用。所有原始事件、最终文本、用量与失败回执保留。价格未知，不能报金额。

模型返回5条理解、2条线索、4条精确原文，并选中7个完整来源。四条原文全部编译成功，模型无需提供字符偏移或哈希。最终在 `prepare` 的视图字节限制处失败，没有导出、没有安装、没有推进游标，也没有父代理删减结果后重试。

### 失败原因拆分

1. **本次探测配置错误**：使用32,768字节的默认视图上限，但当前保守规则必留消息的空视图已经需要 **83,223字节**。无论模型如何选择都无法通过。这个下界在调用前即可确定，原入口却仍调用了模型；本次费用不是可忽略的“准备开销”。
2. **选择仍偏宽**：模型选择了数段完整工具结果，同时另写理解与引用。这是观察到的选择行为；不能仅修正上限就宣称净收益，更不能将生成成功等同于后续使用成功。
3. **评价尚未闭环**：本次没有后续任务质量结果；输入含原生启动材料和完整选择历史，额外生成成本必须进入后续完整经济评价。不能与先前手选 C 的成绩直接拼接。

## 调用前准入修复

结构性根因：强制保留材料的大小由运行时规则决定，却只在付费生成之后校验。

阻止同类事故的规则：生成前在当前数据库快照验证边界内计算空视图下界；如已超过视图上限，拒绝调用。`view_budget.py` 与准备入口共享必留来源规则，不信任调用者可构造的 `Snapshot.events`。

回归反例在修复前明确失败：本应0调用，实际调用了1次模型替身；修复后0调用、0尝试记录。恰好容纳必留材料的视图仍可生成，可省略的普通观察不计入下界。原材料上限和完整候选上限继续分别生效。

用真实失败来源离线重放同一32 KB配置，当前入口在调用前返回 `mandatory_view_byte_budget_exhausted`，没有新模型调用。这是准入修复证据，不是把原生失败运行改写成通过。原始失败版本保留为 `../versions/20261023-quote-selection-v1.zip`。

另在接入精简呈现器时复现一项既有纯代码缺陷：`Excerpt.historical_locator` 允许为 `None`，但 `FactualCodexCheckpointAdapter` 直接拼接字符串，合法的无位置标签摘录因此导出失败。真实生成/准备/导出链路反例先失败，修复后通过；没有位置时省略该标签，原文、来源和原观察时间保持不变。该修复也覆盖其继承适配器所用的同一呈现函数。
