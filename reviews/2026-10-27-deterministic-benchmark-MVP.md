# 确定性 Benchmark 首版：框架可运行，真实原生配对尚未完成

按用户给出的调查→设计→实现→自测→执行→报告顺序推进。旧长程自由开发评测保持退役，既有修复不撤销，WSC 核心算法和 B 原生默认行为未改。

## 调查结论

WSC 的真实入口是 capture/material、prepare 或 generate，以及 stage/install/read。SQLite 保存事件、理解、视图、操作和用量；语义选材由调用方 GeneratorPort 提供，核心不自带模型或触发器。当前原生接入代码确有 thread/compact/start，并能归档用量与 replacement_history；归档中的 compaction 内容加密，不可读。显式 CLI/model/effort 固定不等于内部摘要模型、温度、随机种子或提示词可控。

本机有 Python 3.11、pytest、matplotlib，无 tiktoken/tokenizers。未把 UTF-8 字节当作 token。当前不能声称严格算法级等 Token 对照可执行。真实原生归档可以审计成本和边界，但与新测试流不匹配，不能列入配对语义分数。

## 已实现

独立 benchmarks/deterministic_v1 包含数据生成、适配器、运行器、确定性评分、指标和报告模块。CLI 可选适配器、种子、轮数、数据/答案文件、字节预算、Token 预算准入、恢复预算、正常 WSC 生成命令、原生归档和失败重放。重复运行要求新目录，旧失败保留。

公开数据是带有效期、优先级、依赖和任务的事实事件；标准答案单独绑定数据 hash，不传给压缩适配器。所有压缩完成前，不在磁盘写标准答案或逐轮评分。测试验证了这一点。它是普通适配器的数据隔离，不是针对任意恶意本机进程的安全沙箱。

共享评分器按明确协议还原状态，比较完整类型和值及版本依赖，不用关键词判断。约束反转、过时状态、错误关系有反例；无法解释的自然语言/加密内容是不可判定，不算对或错。各类别单列正确/错误/不可判定、覆盖率及可判定准确率，不给综合分。

固定全选/空选调用真实 WSC prepare/stage/read，属于机制对照，不是实际语义选材质量。没有伪造 HostReceipt；连续 stage 不冒充连续安装或真实自动压缩。另有正常 JsonCommandGenerator 接口，但本轮没有启动任何选材模型。

## 执行与结果

评分器和框架自身9项定向测试通过，包含输入/答案隔离、预算、冷读取与正反例。只运行小规模验收；没有调用评分模型、选材模型或原生新推理。

1. paired-mechanism-v2：相同5轮、相同种子和每轮2条噪声，原始历史对照与固定全选 WSC 共10格全部完成，每格10个结构化问题可验证。双方全部正确。这是完整保留机制的基本校验，不是有意义的语义压缩优势。
2. cold-v2：固定空选的 WSC 5轮全部完成，热材料593字节，10问均不可判定；通过真实 read API 和声明的顺序扫描策略，恢复后各轮10问均正确。I/O 从13次/13,906字节增长到49次/55,434字节。恢复预算是128次/262,144字节，不能和热32,768字节直接称等资源收益，也没有证明模型会主动定位正确证据。
3. 更早 full-v1 压力格有2次 WSC 内部 view_byte_budget_exhausted，原结果全部保留。内部视图序列化预算与实际模型可见上下文字节不同，此失败不能归因于语义丢失。
4. 真实 B-seed-v2 原生压缩归档导入成功，观察到1个压缩边界；数据不匹配，paired=false。没有将它算成真实新基准对照或把加密语义计零。

已输出 JSON/CSV/Markdown、结构化热数据的字节—保真曲线、多 stage 变化曲线与限定范围 Pareto；已查看图像。图中标明不是 Token、不是原生压缩。Token—保真曲线当前不可提供，未伪造。源代码 hash、输入 hash、逐格产品与失败也已记录。

## 尚未完成

实际语义选材器与新数据的绑定、同输入真实 Codex 压缩、经验证的共同 Tokenizer/容量、同资源恢复、多次真实压缩10/20/50轮、自由文本语义和随机实验统计仍未完成。本轮没有证明 WSC 优于原生，不能凭机制对照绿色结果声称整个 Benchmark 或原目标已验收。

当前数据只是小型结构化协议，类别元数据不等于12类自然语言问题均已覆盖。后续需扩展真实轨迹案例和故障变异、避免答案协议可解析性本身造成优势；无法解释的结果只能报告覆盖率，不能拿来和100%结构化覆盖方案直接排名。
